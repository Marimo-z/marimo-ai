# Marimo 桌宠

常驻 Windows 桌面的 AI 桌宠：可在蓝色圆球和带星环的星球之间切换形象，可置顶、拖动、眼睛跟随鼠标、显示说话气泡。
当前已完成 **阶段 6：坦克大战**（井字棋、五子棋、本地语音）。安装包仍未做。

## 环境要求

- Windows 10/11
- Node.js ≥ 22.12（开发时使用 24.x）
- npm ≥ 10

## 安装与运行

```powershell
npm install

# Electron 44 在首次运行时才下载二进制；国内网络建议先设置镜像
$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"
npx install-electron

npm run dev        # 开发模式（渲染进程热更新；修改 electron/ 下代码需重启）
```

## 交互方式

- **左键单击**：机器人弹一下并说一句模拟台词。
- **左键双击**：围绕桌宠弹出一圈快捷菜单（对话框、麦克风、语音播报、控制面板），按钮会从桌宠向外展开，关闭时收回。再双击，或点菜单外，关闭菜单。可在"桌宠设置"中改为不响应。
- **对话框**：桌宠下方一条毛玻璃输入框，不显示历史记录。回车或点发送。
- **麦克风**：点一次进入持续语音。说完停顿约 2.5 秒会自动识别并回复，然后继续听；再点一次结束。桌宠朗读时默认不收音，除非在语音设置里打开「打断语音」。
- **按住拖动**：移动桌宠；松手后不会误触发单击，位置会被记住。
- **右键**：原生菜单（聊天、小游戏、设置、说句话、表情演示、眼睛跟随、待机动画、免打扰、鼠标穿透、隐藏、退出）。
- **托盘图标**：左键显示/隐藏；右键菜单包含控制面板、聊天、设置、置顶、眼睛跟随、待机动画、免打扰、鼠标穿透、退出。
- **鼠标穿透模式**：桌宠变为半透明且不拦截点击；可通过托盘或控制面板关闭。
- **再次启动程序**：不会开第二个实例，而是显示桌宠并打开控制面板。

## 控制面板

独立窗口，左侧导航，七个页面：

| 页面       | 内容                                                                                                                                      |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 聊天       | 与当前启用的 AI 多轮对话；回复同步到桌宠气泡和表情；可停止回复、清空记录                                                                  |
| 总览       | 桌宠预览（眼睛跟随鼠标）、AI / 语音 / 桌宠状态、快捷操作、版本信息、恢复默认配置                                                          |
| AI 配置    | 多个 AI 配置的列表（最多 20 个），选择其中一个启用；每个配置有独立的服务商、模型、参数、API Key 和连接测试                                |
| 人设与记忆 | 名字、性格关键词、说话风格、背景故事、口头禅、回复长度、主动搭话、保存 / 清空对话历史                                                     |
| 语音设置   | 朗读服务（系统语音 / 本地模型 / 在线 / 模拟）、音色、语速、音量、音调、自动朗读、打断语音、识别服务、麦克风与识别测试、本地模型下载与导入 |
| 桌宠设置   | 大小、待机动画、眼睛跟随、灵敏度、置顶、鼠标穿透、气泡停留时间、免打扰、双击行为、开机启动                                                |
| 游戏中心   | 井字棋、五子棋、坦克大战；默认难度、游戏中对话与嘲讽强度、最近战绩                                                                        |

"AI 配置"中每个配置的表单和"人设与记忆"使用"保存 / 撤销修改"；AI 列表的添加、复制、删除、启用，以及其他页面的修改都立即生效。

### AI 配置列表

- 右上角"添加 AI"选择服务商预设（DeepSeek、通义千问、OpenAI、Ollama、自定义，均为 OpenAI 兼容接口），会自动填好地址和推荐模型。
- 列表中点圆点启用，点条目编辑；同一时间只有一个配置处于启用状态，也可以全部停用。
- 复制配置时不会复制 API Key；删除配置会同时删除它的 API Key。
- 从旧版本升级时，原来的单个配置会变成名为对应服务商的配置并保持启用，已保存的密钥自动归到它名下。

外观支持 **系统 / 浅色 / 深色** 三种模式（侧栏底部切换）。浅色为蓝白，深色为深蓝黑，强调色都取自 logo 的蓝色，与桌宠形象保持一致。

### 聊天

- 入口：桌宠右键 / 托盘 → 聊天，或总览页"开始聊天"。Enter 发送，Shift + Enter 换行，回复中可点"停止"。
- 模型按人设回复，并以 JSON 返回文本和表情（平静 / 好奇 / 开心 / 生气 / 难过 / 思考）；等待回复时桌宠显示"思考"，回复后用气泡说出来并切换表情。
- 模型输出不是合法 JSON 时按普通文本显示（表情为平静）；表情不在允许范围内时一律当作平静。模型只能聊天，不能执行任何操作。
- 上下文取最近 20 条、约 6000 字以内的消息。
- 没有启用 AI、缺少密钥、网络失败、超时等情况都会给出明确提示，桌宠也会用难过的表情说明原因。
- 想先离线体验，可以在 AI 配置中添加"模拟（离线测试）"并启用。
- **主动搭话**（人设页，默认关闭）：用户超过设定时间没有聊天时，桌宠会主动说一句话；免打扰、鼠标穿透或桌宠隐藏时不会触发。每次都会请求模型，会消耗少量额度。

### 语音

- **朗读**：默认使用 Windows 系统语音（免费、离线，自动选择中文语音，如 Huihui / Yaoyao / Kangkang）。也可以选择本地模型 Kokoro（离线、100 个中文音色，需先下载模型），或 OpenAI 兼容的在线接口 `POST {Base URL}/audio/speech`（预设：硅基流动 CosyVoice、OpenAI），在线服务按量收费。
- **什么时候朗读**：开启"自动朗读"后朗读每条回复；用语音输入发送的消息，回复总会朗读。模型把某句标记为不适合朗读时（`speech: false`）不读；免打扰模式下不读。
- 朗读时气泡一直显示到读完，桌宠处于说话状态；点击气泡上的 ×、聊天页的"停止朗读"或语音设置页的"停止"都能停下。「打断语音」默认关闭：桌宠正在朗读时，麦克风不会打断它；在语音设置里打开后，语音输入才会打断当前朗读。
- **语音输入**：聊天页或桌宠快捷菜单里点击麦克风开始录音，再点一次结束（最长 60 秒），识别出的文字会直接发送。默认使用本地模型 SenseVoice（离线，中文 / 粤语 / 英语 / 日语 / 韩语，带标点）；也可以改用 OpenAI 兼容的 `POST {Base URL}/audio/transcriptions`（预设：硅基流动 SenseVoice、OpenAI Whisper、Groq Whisper），需要单独的 API Key；DeepSeek 不提供语音接口。
- 录音只在点击麦克风后进行，转换为 16 kHz 单声道 WAV。本地识别时录音不离开本机；选在线服务时由主进程上传给所配置的服务。录音都不保存到本机。
- **本地模型**：语音设置页底部的"本地模型"中一键下载（逐个文件下载并校验 SHA-256，可暂停、断点续传；默认从国内镜像 hf-mirror.com 下载，也可改为 huggingface.co）。下载慢时，可以自行下载 Hugging Face 仓库 [`csukuangfj/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17`](https://huggingface.co/csukuangfj/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17)（需要 `model.int8.onnx`、`tokens.txt`）和 [`csukuangfj/kokoro-int8-multi-lang-v1_1`](https://huggingface.co/csukuangfj/kokoro-int8-multi-lang-v1_1)，或 sherpa-onnx 发布页的同名压缩包解压后，点"导入文件夹"。
- 本地模型由 [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) 在独立的系统 Node 进程中运行（CPU）。开发时使用 PATH / `npm` 提供的 `node.exe`；Electron 本身不能接收 Kokoro 返回的音频缓冲。首次使用需要加载几秒，5 分钟不用会自动释放内存；该进程崩溃不会影响桌宠。
- 权限被拒绝、没有麦克风、麦克风被占用、没有声音、网络失败、限流、超时都会给出提示。如果提示权限被拒绝，请在 Windows 设置 → 隐私和安全性 → 麦克风 中允许桌面应用访问麦克风。

### 游戏

- **井字棋 / 五子棋**：游戏中心点「开始」。可选先手和三档难度；支持暂停、继续、重开和返回。对局中桌宠进入 playing 状态，并用气泡点评（可关、可调频率和嘲讽强度）。结束的对局记入战绩；中途离开不记。
- 困难井字棋使用最优策略，桌宠不会输（最多平局）。五子棋困难会在落子附近做短搜索，先保证规则正确和响应速度。
- **坦克大战**：方向键或 WASD 移动，空格射击。每次开局是一张更大的随机地图，砖墙可被打碎，钢墙挡路也挡弹。捡到星会加速，两颗星后炮弹可以打碎钢墙；盔给短暂护盾，钟冻结敌人，雷清掉场上敌人，心回复 1 点生命（上限 5）。简单 2 辆敌坦，普通 3 辆，困难 4 辆且血更厚、开炮更勤。玩家开局 3 点生命，打光或清完敌方即结束。

### 数据存放位置

- `%APPDATA%\marimo\config.json`：普通配置，不含任何密钥。
- `%APPDATA%\marimo\chat-history.json`：聊天记录（明文，最多 200 条），仅在开启"保存对话历史"时写入；关闭该选项或清空记录时删除。
- `%APPDATA%\marimo\models\`：下载或导入的本地语音模型（SenseVoice 约 228 MB，Kokoro 约 185 MB），可在语音设置中删除。
- `%APPDATA%\marimo\game-records.json`：井字棋 / 五子棋战绩（最多 50 局，不含未完成的对局）。
- `%APPDATA%\marimo\secrets.json`：每个 AI 配置的 API Key，以及在线朗读、在线识别各自的 API Key，经 Electron `safeStorage`（Windows DPAPI，绑定当前系统用户）加密后的密文。渲染进程只能查询"哪些配置已设置密钥"，无法读回明文。

"测试连接"由主进程请求 `GET {baseUrl}/models`。除 `localhost` 外必须使用 HTTPS；结果只显示错误类别（密钥无效、地址错误、超时等），不会显示密钥或服务器原始响应。

## 阶段 1 手动验收步骤

1. `npm run dev`，桌宠出现在主屏幕右下角，背景透明、无白色矩形，并弹出问候气泡。
2. 在屏幕任意位置移动鼠标，眼睛平滑地朝向鼠标；鼠标靠近时眼睛略微放大（curious）。
3. 单击机器人：有挤压回弹反馈，气泡逐字显示，表情随台词变化。
4. 拖动机器人到别处：拖动中机器人缩小倾斜、眼睛眯起；松手后不弹出单击台词。
5. 右键 → 表情演示，依次查看 平静 / 好奇 / 开心 / 生气 / 难过 / 思考。
6. 右键 → 说句话，会随机出现长文本（测试换行与滚动）和无空格超长英文（测试断行）；点击气泡可展开，点 × 关闭。
7. 托盘 → 鼠标穿透：桌宠半透明，点击会穿透到下面的窗口；再次在托盘取消即可恢复。
8. 退出后重新启动，桌宠出现在上次的位置；若该位置所在的显示器已断开，会自动回到主屏幕。
9. 在任务管理器中观察：静止时 CPU 占用应很低（见 `docs/development-log.md` 中的实测数据）。

## 阶段 2 手动验收步骤

1. 双击桌宠，出现快捷菜单；点菜单上的控制面板打开窗口，再点一次只会聚焦已有窗口，不会开第二个。再双击桌宠或点菜单外会关掉菜单。
2. 侧栏底部切换 浅色 / 深色 / 系统，标题栏按钮颜色随之改变；重启后保持选择。
3. 桌宠设置：拖动"大小"滑块，桌宠实时缩放；关闭"始终置顶"、开启"免打扰"，效果立即生效；点"重置到主屏幕右下角"。
4. 人设与记忆：把名字改成别的并保存，总览和桌宠问候语使用新名字；修改后点"撤销修改"可还原。
5. AI 配置：添加一个"通义千问"和一个"Ollama"配置，列表中出现 3 项；点 Ollama 的圆点启用，"启用中"标记随之移动，总览页的 AI 卡片显示 Ollama。
6. 编辑某个配置时切换服务商，Base URL 和模型自动填充；把地址改成 `http://example.com`，会出现 HTTPS 警告，测试连接会被拒绝；有未保存修改时切换到其他配置会提示放弃修改。
7. 为某个配置填入 API Key 并保存：只有该配置显示"已加密保存"；`config.json` 中没有密钥，`secrets.json` 中只有以 `ai:<配置 ID>` 命名的密文。删除该配置后，对应密文也会消失。
8. 有真实密钥时点"测试连接"，应显示延迟和模型是否可用；填错密钥应显示"密钥无效"。
9. 语音设置：点"播放"，桌宠以气泡显示预览文本（阶段 4 起会同时朗读）。
10. 总览 → 恢复默认配置（会二次确认），除 AI 配置列表外的页面都回到默认值；AI 配置和密钥保持不变。
11. 手动把 `config.json` 某个字段改成非法值后重启：只有该字段回到默认值，其余设置保留。

## 阶段 3 手动验收步骤

1. 在 AI 配置中停用全部配置，打开"聊天"：页面顶部提示未启用 AI；发送消息会提示去启用，桌宠显示难过表情并说明原因，输入的文字不会丢失。
2. 启用一个没有密钥的在线配置：提示缺少 API Key。
3. 添加并启用"模拟（离线测试）"：发送"你好"，桌宠先显示思考，再用气泡回复并切换为开心。
4. 启用真实配置（例如 DeepSeek）：多轮对话中模型能记住上文；回复会同步到桌宠气泡。
5. 发送后立即点"停止"：请求被取消，不显示错误，桌宠恢复平静。
6. 把超时改为 3 秒并断开网络后发送：显示网络错误或超时，应用不崩溃。
7. 发送 `<b>粗体</b>` 或让模型输出 HTML：文本原样显示，不会被当作 HTML 渲染。
8. 开启"保存对话历史"后重启：聊天记录还在；关闭该选项后，`chat-history.json` 被删除。
9. 人设页开启主动搭话，把间隔设为 5 分钟，5 分钟内不聊天：桌宠主动说一句话，聊天页中标记为"主动搭话"；开启勿扰后不再触发。

## 阶段 4 手动验收步骤

1. 语音设置 → 朗读选"Windows 系统语音"，在"试听"中点"播放"：能听到中文朗读，桌宠气泡显示同样的文字并处于说话状态；朗读中点"停止"立即停下。
2. 切换音色、调整语速 / 音量 / 音调后再试听：效果随之变化。
3. 点"测试麦克风"并说话：音量条有变化，结果显示"麦克风工作正常"；不说话时提示没有检测到声音。
4. 识别选"模拟"，点"测试识别"→"结束并识别"：显示固定的模拟文本。
5. 识别选在线服务（例如硅基流动 SenseVoice）并保存 API Key，再测试识别：显示你说的话。
6. 聊天页点击麦克风，说一句话后再点一次：识别出的文字作为消息发送，回复会朗读出来。
7. 关闭自动朗读，用键盘发送消息：回复不朗读；打开后会朗读。开启免打扰后不朗读。
8. 朗读选在线服务但不填密钥：试听提示缺少 API Key；聊天回复仍然以气泡显示，并提示语音合成失败。
9. 在 Windows 隐私设置中关闭麦克风权限后点击麦克风：提示权限被拒绝以及如何开启。

## 本地语音手动验收步骤

1. 语音设置 → 本地模型：点 SenseVoice 的"下载"，进度条和已下载大小持续变化；中途点"暂停"再点"下载"，从中断处继续。完成后显示"已就绪"。
2. 识别选"本地模型 SenseVoice"，断开网络后点"测试识别"：仍能识别你说的话，第一次稍慢，之后很快。
3. 下载 Kokoro，朗读选"本地模型 Kokoro"，选择一个音色后试听：能听到中文朗读；切换女声 / 男声、调整语速后效果随之变化。
4. 删除 Kokoro 后试听：提示模型尚未下载，桌宠仍以气泡显示文本。
5. 点"导入文件夹"，选择手动下载并解压的模型文件夹（或它的上一级文件夹）：导入后显示"已就绪"；选择不含模型的文件夹会提示缺少哪些文件。

## 阶段 5 手动验收步骤

1. 游戏中心点井字棋「开始」，用简单难度下完一局：能分出胜负或平局，桌宠有气泡，战绩出现一条；点暂停后不能落子，继续后可下。
2. 困难模式让桌宠后手，随便下：桌宠不会输。
3. 五子棋下一局连成五子（或让桌宠连成）：规则判定正确，返回游戏中心后战绩增加。
4. 关掉「游戏中对话」再下一局：桌宠不再为落子说话，战绩仍会记录。
5. 坦克大战：方向键移动、空格射击，能打掉砖墙；贴着砖墙拐弯时坦克会滑进通道，两辆车撞在一起后还能分开；暂停后坦克不动；捡到道具会改变生命、护盾或敌方；消灭敌人或生命耗尽后出现战绩。
