# Marimo 桌宠

常驻 Windows 桌面的 AI 桌宠：一个蓝色悬浮球机器人，可置顶、拖动、眼睛跟随鼠标、显示说话气泡。
当前已完成 **阶段 2：控制面板与配置**。AI 对话（阶段 3）、真实语音（阶段 4）和小游戏（阶段 5/6）尚未接入，相关入口标注为"即将推出"。

## 环境要求

- Windows 10/11
- Node.js ≥ 22.12（开发时使用 24.x）
- npm ≥ 10

## 安装与运行

```powershell
npm install

# Electron 44 在首次运行时才下载二进制；国内网络建议先设置镜像
$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"
npx install-electron

npm run dev        # 开发模式（渲染进程热更新；修改 electron/ 下代码需重启）
```

## 交互方式

- **左键单击**：机器人弹一下并说一句模拟台词。
- **左键双击**：打开控制面板（可在"桌宠设置"中改为不响应）。
- **按住拖动**：移动桌宠；松手后不会误触发单击，位置会被记住。
- **右键**：原生菜单（小游戏、设置、说句话、表情演示、眼睛跟随、待机动画、免打扰、鼠标穿透、隐藏、退出）。
- **托盘图标**：左键显示/隐藏；右键菜单包含控制面板、设置、置顶、眼睛跟随、待机动画、免打扰、鼠标穿透、退出。
- **鼠标穿透模式**：桌宠变为半透明且不拦截点击；可通过托盘或控制面板关闭。
- **再次启动程序**：不会开第二个实例，而是显示桌宠并打开控制面板。

## 控制面板

独立窗口，左侧导航，六个页面：

| 页面       | 内容                                                                                              |
| ---------- | ------------------------------------------------------------------------------------------------- |
| 总览       | 桌宠预览（眼睛跟随鼠标）、AI / 语音 / 桌宠状态、快捷操作、版本信息、恢复默认配置                  |
| AI 配置    | 服务商预设（DeepSeek、通义千问、OpenAI、Ollama、自定义，均为 OpenAI 兼容接口）、测试连接、API Key |
| 人设与记忆 | 名字、性格关键词、说话风格、背景故事、口头禅、回复长度、主动搭话（阶段 3 生效）                   |
| 语音设置   | 目前只有模拟服务；音色、语速、音量、音调参数先保存，阶段 4 接入真实服务                           |
| 桌宠设置   | 大小、待机动画、眼睛跟随、灵敏度、置顶、鼠标穿透、气泡停留时间、免打扰、双击行为、开机启动        |
| 游戏中心   | 三个游戏（即将推出）、默认难度、游戏中对话与嘲讽强度                                              |

"AI 配置"和"人设与记忆"使用"保存 / 撤销修改"；其他页面修改后立即生效。

外观支持 **系统 / 浅色 / 深色** 三种模式（侧栏底部切换）。浅色为蓝白，深色为深蓝黑，强调色都取自 logo 的蓝色，与桌宠形象保持一致。

### 数据存放位置

- `%APPDATA%\marimo\config.json`：普通配置，不含任何密钥。
- `%APPDATA%\marimo\secrets.json`：API Key 经 Electron `safeStorage`（Windows DPAPI，绑定当前系统用户）加密后的密文。渲染进程只能查询"是否已设置"，无法读回明文。

"测试连接"由主进程请求 `GET {baseUrl}/models`。除 `localhost` 外必须使用 HTTPS；结果只显示错误类别（密钥无效、地址错误、超时等），不会显示密钥或服务器原始响应。

## 阶段 1 手动验收步骤

1. `npm run dev`，桌宠出现在主屏幕右下角，背景透明、无白色矩形，并弹出问候气泡。
2. 在屏幕任意位置移动鼠标，眼睛平滑地朝向鼠标；鼠标靠近时眼睛略微放大（curious）。
3. 单击机器人：有挤压回弹反馈，气泡逐字显示，表情随台词变化。
4. 拖动机器人到别处：拖动中机器人缩小倾斜、眼睛眯起；松手后不弹出单击台词。
5. 右键 → 表情演示，依次查看 平静 / 好奇 / 开心 / 生气 / 难过 / 思考。
6. 右键 → 说句话，会随机出现长文本（测试换行与滚动）和无空格超长英文（测试断行）；点击气泡可展开，点 × 关闭。
7. 托盘 → 鼠标穿透：桌宠半透明，点击会穿透到下面的窗口；再次在托盘取消即可恢复。
8. 退出后重新启动，桌宠出现在上次的位置；若该位置所在的显示器已断开，会自动回到主屏幕。
9. 在任务管理器中观察：静止时 CPU 占用应很低（见 `docs/development-log.md` 中的实测数据）。

## 阶段 2 手动验收步骤

1. 双击桌宠，打开控制面板；再次双击只会聚焦已有窗口，不会开第二个。
2. 侧栏底部切换 浅色 / 深色 / 系统，标题栏按钮颜色随之改变；重启后保持选择。
3. 桌宠设置：拖动"大小"滑块，桌宠实时缩放；关闭"始终置顶"、开启"免打扰"，效果立即生效；点"重置到主屏幕右下角"。
4. 人设与记忆：把名字改成别的并保存，总览和桌宠问候语使用新名字；修改后点"撤销修改"可还原。
5. AI 配置：切换服务商，Base URL 和模型自动填充；把地址改成 `http://example.com`，会出现 HTTPS 警告，测试连接会被拒绝。
6. 填入 API Key 并保存：状态变为"已加密保存"；打开 `config.json` 确认其中没有密钥，`secrets.json` 中只有密文。
7. 有真实密钥时点"测试连接"，应显示延迟和模型是否可用；填错密钥应显示"密钥无效"。
8. 语音设置：点"播放测试文本"，桌宠以气泡显示预览文本。
9. 总览 → 恢复默认配置（会二次确认），所有页面回到默认值，已保存的密钥不受影响。
10. 手动把 `config.json` 某个字段改成非法值后重启：只有该字段回到默认值，其余设置保留。
